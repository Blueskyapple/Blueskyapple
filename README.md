# TikTok Clone

A full-featured TikTok clone built with vanilla HTML, CSS, and JavaScript. Mobile-first design with a dark theme and smooth animations.

## Features

- **Vertical Video Feed** - Swipe up/down to browse videos (touch & mouse wheel)
- **Double-tap to Like** - Heart animation on double-tap
- **Like, Comment, Bookmark, Share** - Full interaction sidebar
- **Comments Panel** - View and add comments with slide-up panel
- **Share Panel** - Share to WhatsApp, Twitter, Telegram, Facebook, Reddit
- **Discover Page** - Trending tags and video grid
- **Upload Page** - Upload interface with drag-and-drop area
- **Inbox Page** - Notifications and messages
- **Profile Page** - Stats, bio, video grid, liked videos tabs
- **Keyboard Navigation** - Arrow keys, J/K to scroll, L to like, C for comments, S to bookmark
- **Play/Pause** - Tap to toggle, visual indicator
- **Progress Bar** - Animated progress bar per video
- **Spinning Music Disc** - Animated album art
- **Responsive** - Works on mobile and desktop (centered on larger screens)

## How to Run

Open `index.html` in any web browser. No build tools or dependencies required.
